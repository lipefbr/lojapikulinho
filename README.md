# 🧸 Loja Pikulinho - Moda Infantil

Loja virtual de roupas infantis em português brasileiro. E-commerce completo com design moderno, colorido e divertido para crianças!

## 🛒 Funcionalidades

- **Catálogo de Produtos** - Listagem com filtros por categoria, faixa etária e preço
- **Detalhes do Produto** - Página dedicada com imagens, tamanhos, avaliações
- **Carrinho de Compras** - Adicionar, remover e alterar quantidades
- **Checkout** - Pagamento simulado via Pix, Cartão de Crédito e Boleto
- **Cadastro/Login** - Autenticação de usuários
- **Minha Conta** - Gerenciamento de perfil, pedidos e endereços
- **Favoritos** - Lista de desejos
- **Cupons de Desconto** - Sistema de cupons promocionais
- **Avaliações** - Sistema de reviews nos produtos
- **Design Responsivo** - Mobile-first com navegação otimizada

## 🎨 Tecnologias

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS 4**
- **shadcn/ui** (componentes)
- **Prisma ORM** (SQLite)
- **Zustand** (gerenciamento de estado)
- **Framer Motion** (animações)

## 🚀 Como Rodar

```bash
# Instalar dependências
npm install

# Configurar banco de dados
npx prisma db push

# Rodar em desenvolvimento
npm run dev

# Acessar
# http://localhost:3000
```
